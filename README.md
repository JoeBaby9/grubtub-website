# grubtubrentals.com

Static site for GrubTub Rentals (Padanaram Harbor, South Dartmouth, MA). Hosted on Vercel.

- `index.html` homepage, `blog.html` blog index, one `.html` per blog post
- `styles.css` shared styles, `img/` photos and the hero video
- `vercel.json` clean URLs plus redirects from the old Hostinger pages
